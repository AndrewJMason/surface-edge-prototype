# Surface Edge Order Desk — clickable prototype

Prototype of an order-tracking back office and customer portal for Surface Edge (Wanke Cascade): PO intake from email, queue vs. production, shipment milestones driven by editable lead times, change requests, threaded chats with drafted replies, vendors, customers, and contacts.

Static page, sample data only. Today is pinned to Oct 26, 2026 so the milestone math is stable.
